# Dashboard warning symbols

SVG Repo collection requested for AutoMob:
https://www.svgrepo.com/collection/car-dashboard-signals/

Monochrome source artwork is retained; color and flashing are applied at runtime.
SVG files have been normalized to UTF-8 with their original viewBox and geometry.
